Section 1.1
Overview

Executive Summary

This project delivers a complete Battery Management and Communication System (BMS) for a 10s1p lithium-ion battery pack. The system combines:

  • High-voltage battery sensing and protection.
  • An isolated embedded control and communication layer.
  • A desktop dashboard for real-time monitoring, command/control, and firmware update support.

The architecture is intentionally split between a battery domain and a host-computer domain to improve safety and reduce fault propagation risk.

Section 2
Theory

Theoretical Basis: Sensing

Current Measurement

Pack current is estimated through a shunt resistor and coulomb-counter readout path. The conversion formula derives from BQ76930 voltage-per-LSB and a 20 mΩ shunt.

Ipack = NLSB × ILSB

Where I_LSB = 0.000422 A/LSB

Thermistor Temperature

Temperature conversion uses a Beta-model NTC equation with parameters R0 = 10 kΩ at 25°C, β = 3950, and a divider supply near 3.3V.

1T = 1T0 + 1β ln RR0

Section 5.1
Firmware

Embedded Firmware

STM32F303 MCU Platform

  • I2C Integration: Used for seamless BQ76930 communication. Auto-detects BMS addresses (0x08/0x18).
  • ADC Channels: Configured for NTC sensing with long sample times for higher-impedance networks.
  • USB Device CDC: Robust interface set up for host communications and telemetry streaming.

Control & Diagnostics

  • Battery IC Wrappers: Register read/write wrappers implemented for SYS_STAT, control, and protection.
  • Fan Control: PWM duty mapping to timer settings. Tachometer capture for RPM calculation.
  • Fault Logic: Explicit fault code branches for hardware errors and short/open circuit conditions.
Section 5.2
Software

Desktop Dashboard Stack

The desktop dashboard provides real-time monitoring and command interfacing.

  • Launcher Layer: PyQt6 windowing with embedded WebEngine frontend and QWebChannel bridge.
  • Serial Parsing: Robust parsing of line-oriented telemetry using regex. Reconstructs frames from mixed streams.
  • Frontend UI: HTML/CSS/JS stack rendering live battery and thermal states.
  • Packaging: Dependency manifests and PyInstaller spec for Windows, macOS, and Linux.

Section 6
Verification

Validation Status

Validation executed via staged testing: module-level checks, parser checks, GUI integration, and end-to-end bench tests.

  • BQ Address Detection Correctly locks to valid address using dual-address probe.
  • CRC Compatibility Correct read/write framing with/without CRC dynamically.
  • NTC Conversion Path Stable conversion under intended long ADC sample timing.
  • Fan PWM & RPM Duty updates reflected in behavior; RPM accurately filtered.
  • Serial Parser Resilience Successfully reconstructs frames from mixed format lines.
  • Command Reliability Commands reach firmware via bridge + polling queue.

Future Roadmap & Conclusion

Future Enhancements
