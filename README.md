# UCR Computer Science & Electrical Engineering

A comprehensive repository containing coursework, lecture notes, labs, and projects from UCR Computer Science and Electrical Engineering programs.

## Directory Structure

### Computer Science Courses

#### **CS061 - Computer Organization**
- Lecture notes and materials on computer architecture, LC-3 assembly, and digital logic
- `Practice Items/` — Practice exams, problem sets, and study guides

#### **CS10B & CS010C - Data Structures**
- **010B/** — Introduction to Data Structures
  - Chapter labs covering arrays, vectors, linked lists, and basic data structures
  - Programming assignments with comprehensive implementations
  - `.vscode/` configuration for C++ development

- **010C/** — Advanced Data Structures
  - Chapters covering stacks, queues, trees, heaps, and graphs
  - Labs and programming assignments with solutions
  - Advanced topics: AVL trees, hash tables, binary search trees

#### **CS162 - Introduction to Computer Architecture**
- Lecture notes and materials on computer architecture and design

### Electrical Engineering Courses

#### **EE114 - Probability, Random Variables, and Random Processes**
- `Lectures/` — Comprehensive lecture notes on probability theory
  - Basics of probability
  - Conditional probability and independence
  - Discrete random variables

#### **EE115 - Introduction to Computer Systems**
- `Lectures/` — Computer systems fundamentals
- Lecture notes covering system design and organization

#### **EE120A - Logic Design**
- `Lectures/` — Complete lecture slide collection
  - Combinational and sequential logic
  - Finite state machines
  - Verilog HDL
  - Datapath components and design
- `Lab Materials/` — Lab manuals and practical exercises

#### **EE133 - Solid State Electronics**
- Lecture notes on semiconductor physics and device theory

#### **EE142 - Intro to Machine Learning and Data Mining**
- `Lectures/` — Course lecture notes
- `Homework/` — Problem sets and datasets
  - Problem Set 1 & 2 with notebooks and datasets
  - IMDB sentiment analysis datasets

#### **EE147 - GPU Programming**
- `Lectures/` — GPU computing and CUDA lecture materials
- `Homework/` — CUDA programming assignments (build with `make` where `nvcc` is available)

#### **EE161 - Computer Design and Architecture**
- `Lectures/` — Architecture and design materials
- `Project/` — Video project phases and scripts
- `Homework/` — Problem sets and assignments

#### **EE168 - Intro to VLSI**
- `Lectures/` — VLSI design course materials
- Chapters on circuit design and layout

#### **EE116 - Electromagnetics**
- Lecture notes and materials

### Additional Resources

- **Books/** — Reference materials and technical documentation
- **STANDARDIZATION_REPORT.md** — Documentation of folder structure standardization

## Contents Summary

- **Lecture Materials:** PDF lecture notes, slides, and course materials
- **Homework & Problem Sets:** Programming assignments and problem-solving exercises
- **Labs:** Hands-on lab work with starter code and solutions
- **Projects:** Semester projects with documentation and implementation

## Development Setup

### For C++ Projects (CS Courses)

The `.vscode/` folders contain pre-configured settings for VS Code development:
- C/C++ compiler configuration
- Debug launch settings
- Build tasks

### For VLSI/HDL Projects

Verilog and hardware design materials are included in the logic design and VLSI courses.

## Getting Started

1. Clone this repository
2. Navigate to your course of interest
3. Review lecture materials in `Lectures/` or `Lecture/` folders
4. Work through labs in chapter-specific directories
5. Complete programming assignments in `Programming Assignment/` folders

## Notes

- Some files may require specific software (MATLAB, Verilog simulators, etc.)
- Large datasets are included for machine learning assignments
- All code follows C++ and Verilog standards appropriate for coursework
