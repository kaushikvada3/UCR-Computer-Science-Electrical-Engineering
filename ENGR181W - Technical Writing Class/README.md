# ENGR181W - Technical Writing Class

Technical writing course (UCR ENGR181W). The graded work centers on a Battery
Management System (BMS) project — essays, an incremental technical report, and a
presentation, all built around that engineering project.

## Contents

- `Course Materials/` — instructor-provided material.
  - `Slides/` — lecture slides (01–11).
  - `Readings/` — articles and IEEE style manuals.
  - `Handouts/` — assignment handouts, presentation guidelines, evaluation criteria.
  - `Sample Papers/` — example papers and abstracts to model writing after.
- `BMS Project/` — my deliverables for the Battery Management System project.
  - `Essays/` — Essay 1, Essay 2, and the Ethics Impact Essay (final versions).
  - `Technical Report/` — the assembled report (`Chapters_1-5`), with the
    section drafts under `Sections/` (Lab 01–08) plus the cover page and checklists.
  - `Presentation/` — final BMS presentation and its PDF preview.
  - `Source Material/` — the EE175 BMS final report and reference papers the writing draws on.
- `Other Assignments/` — coursework not tied to a single BMS deliverable (weekly reports).
- `Scripts/` — Python helpers used to build and format essay/report drafts.
- `Archive/` — superseded drafts and old copies, grouped by artifact.
